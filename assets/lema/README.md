# LEMA 🦉

![LEMA typing](lema-digitando.gif)

LEMA is Franchesca’s ink-blue and ivory owl companion, with a graphite laptop and the GitHub Octocat on its lid. She types in side profile.

The transparent v2 sprite sheet contains 73 frames in an 8 × 11 grid, with 192 × 208 pixel cells. Its nine states are idle, movement right/left, waving, jumping, failure, waiting, working/typing, and reviewing. The final two rows hold sixteen clockwise gaze directions, beginning at up.

GitHub profile READMEs display the looping GIF. State changes and cursor tracking require a player, such as the Pets application; the manifest and individual frames are included for integrations.

Artwork generated with OpenAI image generation and assembled and validated for Pets. The GitHub emblem is a third-party mark, not an original LEMA design.
